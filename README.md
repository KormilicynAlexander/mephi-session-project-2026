# MEPHI Session Project 2026

**Студент:** M265907  
**ОС:** RED OS 8.0.3  
**Имя хоста:** `mephi-2026.domain.local`

## Обязательные файлы

| Файл | Что проверяется |
| --- | --- |
| `mephi-screenshot.png` | Визуальное подтверждение работы web-сервера и отображения страницы `Hello from Student: M265907` |
| `history.out` | История команд, выполненных при настройке системы |
| `ping.out` | Работоспособность сети и доступность `8.8.8.8` |
| `dnf.out` | История транзакций менеджера пакетов `dnf` |
| `stat.out` | Права доступа к `/data/mephi-2026` и SELinux-контекст каталога `/mephi-web` |
| `journalctl.out` | Сообщения журнала сервиса nginx для текущей загрузки системы |
| `getcap.out` | Наличие capabilities `cap_net_admin` и `cap_net_raw` у `tcpdump` |
| `getenforce.out` | Работа SELinux в режиме `Enforcing` |
| `curl.out` | Результат проверки web-сервера через `curl http://localhost/` |
| `fstab` | Автоматическое монтирование файловой системы с меткой `MEPHI_WEB` в `/mephi-web` |
| `passwd` | Созданные пользователи, их UID, домашние каталоги и оболочки входа |
| `shadow` | Настройка срока действия паролей пользователей |
| `group` | Созданные группы, членство разработчиков и кураторов, GID группы `curators` |
| `pwquality.conf` | Политика качества паролей, включая минимальную длину 12 символов |

## Дополнительные файлы

| Файл | Что подтверждает |
| --- | --- |
| `acl.out` | POSIX ACL и default ACL для `/data/mephi-2026`: совместную работу разработчиков, read-only доступ кураторов и отсутствие доступа для остальных пользователей |
| `hostnamectl.out` | Настроенное имя хоста `mephi-2026.domain.local`, версию ОС и сведения о виртуальной машине |
| `lsblk.out` | Структуру дисков, файловую систему ext4, метку `MEPHI_WEB` и её монтирование в `/mephi-web` |
| `nginx-status.out` | Состояние nginx: сервис включён в автозагрузку и находится в состоянии `active (running)` |
| `users.out` | UID пользователей `user1`–`user3` и членство разработчиков и кураторов в соответствующих группах |
